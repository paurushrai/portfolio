# MonoStart project images

`cover.svg` is a **placeholder**. Replace it with the real demo (a screenshot or
animated GIF, matching the other projects in `public/projects/`).

- Easiest: overwrite `cover.svg` with your own `cover.svg`, and nothing else changes.
- If you use a different format (e.g. `cover.gif` / `cover.png`), update the image
  reference in every locale file: `content/projects/*/monostart-chrome-extension.mdx`
  (the line `![...](/projects/monostart-chrome-extension/cover.svg)`).
