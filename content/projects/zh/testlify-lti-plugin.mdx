Canvas、Moodle 和 Blackboard 等学习管理系统 (LMS) 是教育机构和企业培训部门的运营中心。 为了释放 Testlify 对这些庞大生态系统的人才评估功能，需要一个异常安全、合规的桥梁。 作为一名独立的全栈工程师，我积极运作，构建并发布了 **Testlify LTI 插件**，这是一个无缝集成，旨在将 Testlify 直接连接到教师的本机 LMS 环境中。

## 技术范围和架构

- **自定义 LTI 1.3 加密引擎：** 放弃繁重的黑盒第三方 LTI 库，我在 Next.js 14 中从头开始设计了高度安全的自定义实现。我手动执行了严格的 OpenID Connect (OIDC) 握手，处理深度 JWT 签名验证，并建立了安全的 JWKS 公钥端点，以保证 LMS 和平台之间坚不可摧的信任。
- **自动数据同步：** 构建了复杂的 API 层来自动化繁琐的管理工作流程。 我集成了姓名和角色配置服务 (NRPS) 以立即同步大量学生名册，并构建了强大的 Webhook 侦听器，利用作业和成绩服务 (AGS) 将考生评估分数直接无缝推回到 LMS 成绩簿中。
- **全栈系统设计：** 将复杂的多租户 API 路由和精美的、可访问的 React 18 仪表板 UI 统一到单个整体架构中。 我设计了可扩展的 MongoDB 模式来处理安全的 LMS 平台配置，并精心策划了高级 Docker 设置来模拟隔离的 LMS 环境以进行本地测试。

## 业务影响

通过成功设计无摩擦、普遍兼容的 LTI 集成，该项目积极地将 Testlify 的目标市场扩展到高等教育和企业培训领域。 自动单点登录 (SSO) 和自动成绩同步完全消除了管理摩擦，使教师能够轻松采用该平台并推动大规模机构参与。
