我为 [Win Daily Sports](https://windailysports.com/) 在一条自动化流水线之上构建了体育投注预测模型，这条流水线负责拉取、处理并分析大量体育数据。

![Win Daily Sports 仪表盘](/projects/win-daily-sports/image.png)

## 我做了什么

- **ETL 流水线：** 写了抓取脚本，从各种网站和 API 拉取实时和历史体育数据。
- **预测模型：** 构建了分析球员和球队数据的模型，用来找出高价值的投注机会。
- **自动化：** 把从抓取到模型运行的整条流程都自动化了，让数据保持新鲜、几乎不用人工。
- **Google Sheets 交付：** 和分析师一起弄清楚他们实际是怎么工作的，然后通过 API 和 Apps Script 把模型输出接进 Google Sheets -  - 在他们本来就在用的工具里跟他们对接，而不是逼他们去学一个新工具。

## 为什么它有意义

把数据收集和建模自动化，缩短了分析师拿到洞察的时间，这些预测也给了团队一个更一致、有数据支撑的预测依据。
