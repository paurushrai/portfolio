对于 [赢得每日体育](https://windailysports.com/)，我带头开发了高级体育博彩预测模型。 该项目的重点是设计一个完全自动化的数据管道来聚合、处理和分析大量的体育数据。

![Win Daily Sports Dashboard](/projects/win-daily-sports/image.png)

## 主要贡献和成就

- **自动数据管道 (ETL)：** 设计和部署强大的网络抓取脚本，以从各种互联网来源和 API 中提取实时和历史体育数据。
- **预测建模：** 设计复杂的预测模型，旨在分析球员和球队的统计数据，识别高价值的投注机会和可行的见解。
- **工作流程自动化：** 简化了整个数据生命周期（从提取到模型执行），最大限度地减少手动干预并确保数据的新鲜度和准确性。
- **Google Sheets 集成：** 构建并自动化最终交付机制，将投影模型直接集成到 Google Sheets API 和 AppScripts 中。 这为利益相关者提供了直观、动态且易于访问的仪表板，用于实时决策。

## 业务影响

通过自动化数据收集和建模过程，我显着缩短了分析师获得洞察力的时间。 预测模型为团队提供了数据驱动的策略，提高了投注预测的整体质量和准确性，同时扩展了他们的运营能力。
