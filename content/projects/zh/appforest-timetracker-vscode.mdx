我们的 Jira 插件 [Timesheets by AppForest](/projects/timesheets-appforest) 已经把 Testlify 的工时跟踪集中了起来——但开发者仍然得停下手头的活、切换过去手动填报工时。AppForest Timetracker 填补了这个空档。它是一个 VS Code 扩展，直接在编辑器里跟踪编码活动，把工时记录变成一个快捷操作，让工程师不用离开 IDE 就能记录到 Timesheets。从想法到发布上 Marketplace，我从头到尾都负责。

## 我做了什么

- **扩展本身：** 基于官方的 VS Code Extension API 构建，用后台进程安静地跟踪编辑器活跃时间、文件切换和工作区变动——不会打断开发者。
- **感知 Git 的工时记录：** 扩展会读取当前的 Git 分支，从中提取工单 ID，因此它记录到 Timesheets 插件时，捕获的工时已经关联到了正确的 issue——不用去找工单，也不用重新输入。
- **完整生命周期：** 我负责了本地配置的使用体验、令牌的安全存储，以及把构建打包并发布到 Visual Studio Marketplace。

## 为什么它有意义

去掉记录工时的手动步骤，意味着流入 Timesheets 的工时数据更完整、也更准确——记录工时的投入大约减少了 60–70%，报表出错的情况也少了很多。这让管理层拿到了更干净的数据，用来排期和计费。
