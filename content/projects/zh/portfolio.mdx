本作品集是一个基于 **Next.js 14 App Router** 构建的应用，定位为可在线查阅的工程实践样本，而非模板项目。每一个架构决策都体现了企业级系统中同等的生产思维：正确性、可观测性与可量化的性能表现。站点在 Lighthouse 评测中取得了**桌面端 99/100、移动端 97/100 的性能评分**，无障碍访问与 SEO 均达到满分 100。

## 技术范围与贡献

- **12 语言 i18n 架构：** 从零设计并实现了完整的自定义国际化系统，无需任何第三方库。基于强类型翻译映射构建了类型安全的 `LanguageContext`，覆盖英语、德语、西班牙语、法语、印地语、意大利语、日语、韩语、葡萄牙语、俄语、土耳其语和中文共 12 种语言。语言切换器通过 `localStorage` 持久化用户偏好，并动态更新 `<html lang>` 属性，确保屏幕阅读器和搜索爬虫始终获取正确的语言环境。所有面向用户的文字——包括联系表单标签、错误提示和行动号召文案——均已完整本地化至全部 12 种语言。

- **Canvas 动画与性能优化：** 使用原生 Canvas 2D API 实现了媲美 WebGL 效果的粒子系统，具备鼠标磁力吸引、Alpha 渐隐物理效果及平滑边界环绕。定位并消除了一个关键的强制回流瓶颈——将 `getBoundingClientRect()` 调用从高频 `mousemove` 路径中移除，改为仅在 resize 事件时更新的缓存 `ref`，将每帧 DOM 操作复杂度从 O(n) 降至 O(1)。结合 RAF 节流的鼠标状态更新与 `next/dynamic` 懒加载，使粒子系统完全脱离关键渲染路径，推动桌面端 Lighthouse 性能评分达到 **99/100**。

- **无广告拦截盲区的分析方案：** 搭建了双分析栈（Umami + Google Tag Manager），并构建了 Next.js 重写代理，将所有遥测数据通过第一方域名路由（`/um/script.js` → `cloud.umami.is`，`/um/api/send` → `api-gateway.umami.dev`）。这彻底消除了当分析脚本从第三方源加载时（被 uBlock Origin 和 Brave 拦截）通常造成的 20–40% 事件静默丢失。GTM 在服务端管理 GA4 标签，将所有标签治理集中在统一入口。

- **SEO 与结构化数据体系：** 实现了 JSON-LD `Person` 模式、全部 12 种语言的 hreflang 备用链接、每个路由的规范 URL，以及每个项目 slug 的动态 `generateMetadata`。配置 `generateMetadata` 为各项目生成 Open Graph 元数据和 `SoftwareApplication` JSON-LD，通过 Google 结构化数据验证器，并消除了多语言路由之间的重复内容信号。

- **WCAG 2.1 AA 无障碍合规：** 完成了全面的无障碍审计并修复了所有问题——实现了视觉隐藏的"跳至主内容"链接，通过单条 CSS 规则全局强制 `:focus-visible` 键盘焦点环，修正了所有正文文字的前景/背景对比度（深色背景下 zinc-500 → zinc-400，AA 对比度达到 4.5:1 以上），并对装饰性 Canvas 元素应用了 `aria-hidden`。将语言切换器从非语义化的 `listbox` 重构为符合规范的 ARIA `menu` 结构。

- **类型安全内容管道：** 配置 Contentlayer 在构建时将 MDX 项目文件处理为完整类型的静态 JSON，`slug` 和 `locale` 等计算字段均从文件路径结构中自动推导。添加新项目无需修改任何代码——只需将 MDX 文件放入对应语言目录，下次部署后即自动上线。完全消除了运行时解析开销。

- **无服务器页面浏览计数：** 构建了一个无服务器 Edge Function，使用 SHA-256 哈希 IP 地址进行去重的匿名页面浏览计数——无 Cookie，不存储任何个人信息。计数在 60 秒 ISR 窗口内重新验证，使项目浏览量呈现近实时效果，同时不牺牲静态交付模式。
