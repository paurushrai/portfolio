At [FuelBuddy](https://fuelbuddy.in/), I was a core engineer on the Franchise Application, which franchise operators use to manage regional hubs, inventory, and delivery fleets.

## What I built

- **Live truck tracking:** Built an interactive map module displaying real-time fleet locations, giving operators continuous visibility into truck movements and dispatch statuses.
- **GraphQL APIs and query optimization:** Built data APIs using Hasura GraphQL engine, optimizing payloads and query caching to ensure fast response times even over weak cellular connections.
- **Workflow simplification:** Redesigned multi-step operational tasks, such as inventory reconciliation and driver assignment, into streamlined interfaces that reduced operational errors.

## Why it mattered

Real-time fleet tracking made dispatch logistics more predictable and reduced truck idle time. Optimized data fetching and simplified workflows reduced operational errors across franchise hubs.
