Our Jira plugin, [Timesheets by AppForest](/projects/timesheets-appforest), centralized time tracking at Testlify, but developers still had to stop and switch tools to log their hours by hand. The AppForest Timetracker closes that gap. It is a VS Code extension that tracks coding activity right in the editor and turns time logging into a quick action, so engineers can log to Timesheets without leaving the IDE. I owned it end to end, from the concept through publishing on the Visual Studio Marketplace.

## What I built

- **The extension core:** Built on the official VS Code Extension API, with background processes that track active editor time, file switches, and workspace changes quietly without interrupting the developer.
- **Git-aware time logging:** The extension reads the current Git branch and extracts the Jira ticket ID automatically, ensuring logged time is linked to the right issue without manual ticket search or retyping.
- **Full lifecycle:** Handled local settings configuration, secure token storage, packaging, and the release pipeline for the Visual Studio Marketplace.

## Why it mattered

Automating ticket matching from Git branch context eliminated manual timesheet logging steps, reduced reporting mistakes, and gave leadership cleaner data for sprint planning and client billing.
