[GTM Advisors](https://gtmadvisors.com/) needed a marketing site that accurately reflected their advisory consulting practice and performed well in search rankings. I owned the build end to end, choosing a Jamstack architecture to maximize load speed and SEO performance while enabling the marketing team to manage content independently.

![GTM Advisors marketing site homepage](/projects/gtm-advisors/image.png)

## What I built

- **Astro static site:** Built with Astro to ship zero unnecessary client JavaScript by default, achieving strong Lighthouse scores and a fast technical foundation for SEO.
- **Directus CMS:** Decoupled content from the frontend using Directus. Configured SQL schemas and REST API endpoints so the marketing team could update copy and case studies without touching code.
- **Responsive frontend:** Converted visual designs into a responsive, accessible component system structured for long-term maintainability.

## Why it mattered

The Jamstack architecture reduced hosting overhead and gave the marketing team a self-serve content workflow, while fast page load times supported organic search discovery.
