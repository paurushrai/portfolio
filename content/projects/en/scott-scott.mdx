For [Scott+Scott](https://scott-scott.com/), an international litigation law firm, I maintained and modernized their primary web property, focusing on Core Web Vitals optimization and custom frontend components for complex legal publications.

![Scott+Scott international law firm website homepage](/projects/scott-scott/image.png)

## What I did

- **Custom frontend components:** Built responsive UI components within WordPress to make legal case filings, attorney profiles, and practice area documentation easier to navigate.
- **Core Web Vitals optimization:** Audited page performance, implementing asset minification, browser caching, and responsive image delivery to improve Lighthouse scores and page load times.
- **Platform maintenance and reliability:** Managed security updates, database query optimization, and infrastructure stability during high-traffic litigation press releases.

## Why it mattered

Performance and UX optimizations improved Core Web Vitals scores, enhanced search visibility, and ensured high reliability during public case announcements.
