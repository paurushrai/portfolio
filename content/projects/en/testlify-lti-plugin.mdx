Learning Management Systems (LMS) such as Canvas, Moodle, and Blackboard are the primary platforms used by universities and enterprise training teams. To make Testlify assessments accessible within these systems, I designed and built the Testlify LTI integration from scratch as the lead engineer. The integration allows educators to embed Testlify assessments directly into LMS courses and automatically synchronize scores to the gradebook.

![Testlify LTI 1.3 Plugin Demo](/projects/testlify-lti-plugin/plugin.gif)

The integration is **[officially certified by 1EdTech](https://site.imsglobal.org/certifications/testlify-inc/testlify#cert_pane_nid_626241)** for LTI Advantage (v1.3), covering Names and Role Provisioning Services (NRPS 2.0) and Assignment & Grade Services (AGS 2.0).

## What I built

- **Custom LTI 1.3 security layer:** Implemented the full LTI 1.3 security specification in Next.js 14, including OpenID Connect (OIDC) third-party launch flows, RSA SHA-256 JWT signature verification, and dynamic JWKS endpoints.
- **LTI Advantage services:** Built Deep Linking workflows allowing instructors to select assessments from within the LMS, NRPS 2.0 integration to retrieve course rosters, and AGS 2.0 endpoints for automated grade synchronization.
- **Multi-tenant full-stack architecture:** Built a multi-tenant administration dashboard in React 18, configured MongoDB schemas for platform registration keys, and set up Docker Compose environments to test against Canvas and Moodle instances locally.

## Why it mattered

Achieving official 1EdTech certification allowed Testlify to enter higher education and enterprise training markets. The automated roster sync and grade passback eliminated manual data entry for instructors.
