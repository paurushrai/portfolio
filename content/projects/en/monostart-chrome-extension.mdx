MonoStart transforms the default browser new-tab page into a fast, customizable personal dashboard. It organizes bookmarks, task lists, quick notes, and focus timers into a configurable workspace. Built as a Manifest V3 Chrome extension, it operates completely on-device without external tracking.

![MonoStart - Customizable New-Tab Chrome Extension](/projects/monostart-chrome-extension/cover.png)

## What I built

- **Customizable dashboard:** A drag-and-drop grid where widgets (quick links, categorized folders, notes, to-do lists, countdown timers, reminders, and search) can be arranged to match any workflow.
- **Quick access layout:** Pinned links in the header and grouped folders replace deep bookmark menus, keeping frequently accessed sites one click away.
- **Theme customization:** 12 built-in color themes, custom hex picker, light/dark mode support, and gradient or wallpaper backgrounds.
- **Productivity tools:** Built-in countdown timers and scheduled reminders with local audio alerts and desktop notifications.
- **Local-first privacy:** All configuration and data reside exclusively in chrome.storage.local. There are no user accounts, external databases, or analytics tracking.

## Why it mattered

The new-tab page is opened dozens of times daily. MonoStart turns that empty space into an instant, local-first productivity dashboard with zero network latency and complete user privacy.
