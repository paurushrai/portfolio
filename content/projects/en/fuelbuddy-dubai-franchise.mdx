FuelBuddy's UAE expansion required a dedicated franchise application tailored to regional regulatory, security, and operational requirements. I built the Dubai Franchise Application from scratch across both the frontend and the data APIs.

## What I built

- **Greenfield frontend:** Built the component system and application structure from scratch, delivering a clean and responsive interface for franchise operations.
- **Hasura GraphQL APIs:** Built the backend data layer on Hasura GraphQL engine, defining the CRUD operations and data models needed by the application.
- **TanStack Query data layer:** Implemented TanStack Query for caching, background synchronization, and optimistic UI updates, keeping network requests efficient and UI state consistent.
- **Authentication and security:** Configured token management, API payload validation, and role-based access control to meet regional compliance standards.

## Why it mattered

Delivering a dedicated platform satisfied regional compliance requirements in Dubai while establishing a modern architecture with TanStack Query and GraphQL that minimized redundant network calls.
