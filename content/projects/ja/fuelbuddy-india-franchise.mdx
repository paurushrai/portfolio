[FuelBuddy](https://fuelbuddy.in/) では、フランチャイズアプリのコアエンジニアを務めました。これはフランチャイズ事業者が地域拠点を運営し、在庫を管理し、配送フリートを調整するために使うアプリです。

## 作ったもの

- **リアルタイムのトラック追跡:** 要望の多かった追跡モジュールを構築し、フリートの現在地をインタラクティブな地図上に表示しました。事業者はこれまでなかったリアルタイムの可視性を得て、配車の判断の仕方が変わりました。
- **CRUD API とパフォーマンス:** アプリが動く土台となるデータ API を Hasura の GraphQL エンジンで構築し、チューニングしました。ペイロードを再構成し、キャッシュを追加し、重いクエリを減らすことで、応答時間を下げ、回線が弱い場所でもアプリを使える状態に保ちました。
- **ワークフローの再設計:** 在庫の照合やドライバーの割り当てといった複雑な複数ステップの作業を、技術者でないフランチャイズスタッフ向けのよりシンプルなフローに作り直し、運用ミスを減らしました。

## なぜ意味があったか

トラック追跡により物流の予測が立てやすくなり、トラックのアイドル時間が減りました。速くなったバックエンドとシンプルになった UI が相まって、新しいフランチャイズパートナーの立ち上げが早まり、アプリが使いにくいという問い合わせも減りました。
