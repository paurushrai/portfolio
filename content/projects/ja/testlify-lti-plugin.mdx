Canvas、Moodle、Blackboard などの学習管理システム (LMS) は、教育機関や企業トレーニング部門の運用ハブです。 これらの大規模なエコシステムに対して Testlify の人材評価機能を活用するには、非常に安全でコンプライアンスに準拠したブリッジが必要でした。 私は単独のフルスタック エンジニアとして積極的に活動しており、講師のネイティブ LMS 環境内で Testlify を直接接続するように設計されたシームレスな統合である **Testlify LTI プラグイン** を設計して出荷しました。

![Testlify LTI 1.3 Plugin Demo](/projects/testlify-lti-plugin/plugin.gif)

## 技術範囲とアーキテクチャ

- **カスタム LTI 1.3 暗号化エンジン:** 重くてブラックボックス化されたサードパーティ LTI ライブラリを使用せずに、Next.js 14 内で安全性の高いカスタム実装を一から設計しました。厳格な OpenID Connect (OIDC) ハンドシェイクを手動で実行し、詳細な JWT 署名検証を処理し、LMS とプラットフォームの間の侵入不可能な信頼を保証する安全な JWKS 公開キー エンドポイントを確立しました。
- **自動データ同期:** 退屈な管理ワークフローを自動化するために、洗練された API レイヤーを設計しました。 私は、名前と役割のプロビジョニング サービス (NRPS) を統合して、大量の学生名簿を即座に同期し、割り当ておよび採点サービス (AGS) を利用して候補者の評価スコアを LMS 成績表にシームレスに直接プッシュする堅牢な Webhook リスナーを構築しました。
- **フルスタック システム設計:** 複雑なマルチテナント API ルーティングと、洗練されたアクセス可能な React 18 ダッシュボード UI を単一のモノリシック アーキテクチャに統合します。 安全な LMS プラットフォーム構成を処理するためのスケーラブルな MongoDB スキーマを設計し、ローカル テスト用に分離された LMS 環境をシミュレートするために高度な Docker セットアップを調整しました。

## ビジネスへの影響

このプロジェクトは、摩擦のない、世界的に準拠した LTI 統合のエンジニアリングに成功することで、Testlify の対象市場を高等教育およびエンタープライズ トレーニングの分野に積極的に拡大しました。 自動化されたシングル サインオン (SSO) と自動成績同期により、管理上の煩雑さが完全に排除され、講師がプラットフォームを簡単に導入できるようになり、大規模な教育機関の関与が促進されました。
