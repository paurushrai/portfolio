私たちの Jira プラグイン [Timesheets by AppForest](/projects/timesheets-appforest) は、Testlify の工数管理を一元化していました。それでも開発者は手を止めて画面を切り替え、工数を手入力する必要がありました。AppForest Timetracker はそのギャップを埋めます。エディター内でコーディング活動を記録し、工数入力をワンアクションに変える VS Code 拡張機能で、エンジニアは IDE を離れずに Timesheets へ入力できます。アイデアから Marketplace での公開まで、私が一貫して担当しました。

## 作ったもの

- **拡張機能そのもの:** 公式の VS Code Extension API 上に構築し、バックグラウンドプロセスがアクティブなエディター時間、ファイルの切り替え、ワークスペースの変更を静かに記録します。開発者を邪魔するものは何もありません。
- **Git を認識した工数記録:** 拡張機能は現在の Git ブランチを読み取り、そこからチケット ID を取り出します。そのため記録した時間は Timesheets プラグインに入力される時点で正しい課題に紐づいており、チケットを探す手間も再入力も不要です。
- **ライフサイクル全体:** ローカル設定の UX、トークンの安全な保存、そしてビルドを Visual Studio Marketplace 向けにパッケージ化して公開する作業まで、すべて私が担当しました。

## なぜ意味があったか

手作業の工程を工数記録から取り除いたことで、Timesheets に流れ込む時間データはより網羅的かつ正確になりました。工数入力にかかる手間はおよそ 60〜70% 減り、報告ミスも大きく減りました。これにより経営陣は、スプリント計画と請求のためのよりきれいなデータを手にできました。
