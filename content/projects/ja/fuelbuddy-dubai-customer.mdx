FuelBuddy の UAE B2B 市場への進出には、専用の Web アプリが必要でした。現地の法人顧客は、単発の購入をするコンシューマー向けのモバイルユーザーとは働き方が異なり、一括発注やフリート管理を行うからです。私はこのポータルを空のリポジトリから構築する作業を、フロントエンドとその背後の CRUD API まで含めて支援しました。

## 作ったもの

- **土台づくり:** フロントエンドをゼロから立ち上げました。コンポーネント構成、ルーティング、共通のスタイリングシステムを整え、アプリが成長していける確かな基盤を作りました。
- **B2B のワークフロー:** 法人顧客が実際に使う画面を構築しました。複数ステップの発注フォーム、一括発注のフロー、そしてフリートマネージャーが頼りにする情報密度の高いダッシュボードです。
- **機能のオーナーシップ:** 機能をエンドツーエンドで進めました。Hasura の GraphQL エンジン上で CRUD API を作り、そこにデザインとビジネスルールを結びつけ、全体を本番環境まで届けました。

## なぜ意味があったか

このポータルをリリースしたことで、FuelBuddy はドバイの法人顧客向けにきちんとした Web の受け皿を持てました。大口の B2B 燃料注文も出しやすくなり、同社の地域展開を後押ししました。
