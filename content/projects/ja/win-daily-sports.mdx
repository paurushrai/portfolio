[デイリースポーツに勝つ](https://windailysports.com/) では、高度なスポーツ賭博予測モデルの開発の先頭に立ちました。 このプロジェクトは、大量のスポーツ データを集約、処理、分析するための完全に自動化されたデータ パイプラインのエンジニアリングを中心にしていました。

![Win Daily Sports Dashboard](/projects/win-daily-sports/image.png)

## 主な貢献と成果

- **自動データ パイプライン (ETL):** さまざまなインターネット ソースや API からリアルタイムおよび過去のスポーツ データを抽出するための堅牢な Web スクレイピング スクリプトを設計および展開しました。
- **予測モデリング:** プレーヤーとチームの統計を分析し、価値の高い賭けの機会と実用的な洞察を特定するように設計された高度な予測モデルを設計しました。
- **ワークフローの自動化:** データのライフサイクル全体 (抽出からモデルの実行まで) を合理化し、手動介入を最小限に抑え、データの鮮度と正確性を確保します。
- **Google スプレッドシートの統合:** 最終的な配信メカニズムを構築および自動化し、投影モデルを Google Sheets API および AppScript に直接統合しました。 これにより、関係者は、リアルタイムの意思決定を行うための、直観的かつ動的で簡単にアクセスできるダッシュボードを利用できるようになりました。

## ビジネスへの影響

データ収集とモデリングのプロセスを自動化することで、アナリストが洞察を得るまでの時間を大幅に短縮しました。 予測モデルにより、チームはデータ主導の戦略を実現できるようになり、運用能力を拡張しながら、ベッティング予測の全体的な品質と精度が向上しました。
