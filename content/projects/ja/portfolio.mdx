このポートフォリオは **Next.js 14 App Router** で構築した、テンプレートではなく「動くエンジニアリングの証拠」として設計したアプリケーションです。アーキテクチャの各決定は、エンタープライズシステムで求められる本番品質の思考—正確性・可観測性・測定可能なパフォーマンス—に基づいています。サイトは **デスクトップ Lighthouse スコア 99/100・モバイル 97/100** を達成しており、アクセシビリティおよび SEO では満点の 100 を記録しています。

![Personal Portfolio — paurushrai.in](/projects/portfolio/portfolio.gif)

## 技術範囲と実装内容

- **12言語対応 i18n アーキテクチャ:** サードパーティライブラリを一切使わず、完全独自の国際化システムをゼロから設計・実装しました。英語・ドイツ語・スペイン語・フランス語・ヒンディー語・イタリア語・日本語・韓国語・ポルトガル語・ロシア語・トルコ語・中国語の 12 言語にわたる型安全な翻訳マップを持つ `LanguageContext` を構築。言語切り替えはユーザーの選択を `localStorage` に永続化し、`<html lang>` 属性を動的に更新することで、スクリーンリーダーとクローラーが常に正しいロケールを取得できるようにしています。コンタクトフォームのラベル・エラー状態・CTA コピーを含む、すべてのユーザー向け文字列を 12 ロケール全体で完全にローカライズしています。

- **Canvas アニメーションとパフォーマンス最適化:** 生の Canvas 2D API を用い、マウス追従の磁力効果・アルファフェード物理演算・スムーズな境界折り返しを備えた WebGL グレードのパーティクルシステムを実装しました。ホットパス（`mousemove` イベント）上で `getBoundingClientRect()` を呼び出していた強制リフローのボトルネックを特定・除去し、リサイズイベント時のみ更新されるキャッシュ済み `ref` に移行。フレームごとの DOM アクセスを O(n) から O(1) に削減しました。RAF スロットリングによるマウス状態更新と `next/dynamic` による遅延ロードを組み合わせ、パーティクルをクリティカルレンダーパスから完全に切り離した結果、デスクトップ Lighthouse パフォーマンススコア **99/100** を達成しています。

- **広告ブロッカーの盲点を排除したアナリティクス基盤:** Umami と Google Tag Manager によるデュアルアナリティクス構成を構築し、すべてのテレメトリをファーストパーティドメイン経由でルーティングする Next.js リライトプロキシを実装しました（`/um/script.js` → `cloud.umami.is`、`/um/api/send` → `api-gateway.umami.dev`）。これにより、uBlock Origin や Brave によってサードパーティオリジンがブロックされる際に典型的に発生する 20〜40% のサイレントイベントロスを解消しています。GTM はサーバーサイドで GA4 タグを管理し、タグガバナンスを一箇所に集約しています。

- **SEO と構造化データの実装:** JSON-LD `Person` スキーマ、12 ロケール全体への hreflang alternate リンク、ルートごとの canonical URL、および各プロジェクトスラグへの動的 `generateMetadata` を実装しました。`generateMetadata` はプロジェクトごとの Open Graph と `SoftwareApplication` JSON-LD を生成し、Google の構造化データバリデーターを満たすとともに、ローカライズされたルート間の重複コンテンツシグナルを排除しています。

- **WCAG 2.1 AA アクセシビリティ対応:** 完全なアクセシビリティ監査を実施し、すべての問題を修正しました。視覚的に非表示のスキップリンクを実装し、単一の CSS ルールでグローバルに `:focus-visible` キーボードリングを適用。すべての本文テキストで前景色・背景色のコントラスト比を修正し（ダークサーフェス上の zinc-500 → zinc-400 で AA 基準の 4.5:1 以上を達成）、装飾的な canvas 要素に `aria-hidden` を設定。言語切り替えコンポーネントを非セマンティックな `listbox` から適切な ARIA `menu` 構造へリファクタリングしました。

- **型安全なコンテンツパイプライン:** Contentlayer を設定し、ビルド時に MDX プロジェクトファイルを完全に型付けされた静的 JSON に変換。`slug` および `locale` フィールドはファイルパス構造から自動的に導出されます。新しいプロジェクトはコード変更不要で追加でき、正しいロケールフォルダに MDX ファイルを置くだけで次のデプロイ時にサイトへ反映されます。実行時のパース処理は完全に排除しています。

- **サーバーレスによるページビュー計測:** SHA-256 でハッシュ化した IP アドレスを使った重複排除により、Cookie や PII を一切保存しない匿名ページビューカウントのサーバーレス Edge Function を構築しました。カウントは 60 秒の ISR ウィンドウで再検証されるため、静的配信モデルを維持しながらプロジェクトビュー数をほぼリアルタイムに表示できます。

## ビジネスインパクト

このポートフォリオは、意図的な技術力の証明です。パーティクルシステムの強制リフローボトルネックの解消、ファーストパーティアナリティクスプロキシの構築、12 ロケールへのコンテンツ移行—あらゆる最適化は、本番スケールのシステムに適用するのと同じエンジニアリングの厳密さによって行われています。その結果、アクセシビリティと SEO で満点、パフォーマンスで最高水準のスコアを達成し、英語話者以外の数十億人のユーザーにアクセス可能な完全国際化コンテンツと、他の実装が静かに破棄するデータを取得するアナリティクスパイプラインを実現しています。コードベースはオープンソースであり、アーキテクチャ上の判断はすべて検証可能です。
