[GTM Advisors](https://gtmadvisors.com/) は、自分たちのコンサルティングの質に見合い、かつ検索で上位に表示されるサイトを求めていました。私はビルドをエンドツーエンドで担当しました。速度と SEO を得るために意図的に Jamstack を選び、引き渡した後はマーケティングチームが自分たちでサイトを運営できるように整えました。

![GTM Advisors](/projects/gtm-advisors/image.png)

## 作ったもの

- **Astro の静的サイト:** Astro はデフォルトで JavaScript をまったく配信しないため、ページの読み込みが速く、Lighthouse のスコアも良く、SEO のしっかりした技術的土台になりました。
- **Directus CMS:** Directus でコンテンツをフロントエンドから切り離しました。スキーマと REST API を整え、マーケティングチームがコードに触れずに自分でコンテンツを編集できるようにしました。
- **レスポンシブなフロントエンド:** デザインを、サイトが成長しても保守しやすいレスポンシブでコンポーネントベースのフロントエンドに落とし込みました。

## なぜ意味があったか

Jamstack 構成によりホスティングコストが下がり、コンテンツ更新がマーケティングチームのセルフサービスになりました。高速で SEO に強い土台が、彼らの自然検索とリード獲得を支えています。
