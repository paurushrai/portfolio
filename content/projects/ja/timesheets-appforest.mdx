Testlify に在籍中に、私は重大な運用上のボトルネックを特定しました。会社は、実際のエンジニアリング ワークフローとの緊密な統合を欠いた、切り離されたサードパーティの時間追跡ツールに資本を費やしていました。 私は専任の社内チームと協力して、**Timesheets by AppForest** のフロントエンド エンジニアリングを主導しました。これは、時間追跡、リアルタイムの生産性に関する洞察、および詳細なコスト割り当てをシームレスに処理するように設計された、カスタム構築されたエンタープライズ グレードの Jira プラグインです。

![Timesheets by AppForest — Overview](/projects/timesheets-appforest/timesheet.gif)

## 技術範囲と貢献

- **Atlassian エコシステムの統合:** 複雑な Jira Developer API と UI フレームワークをナビゲートして、Atlassian Marketplace 向けにネイティブに構築しました。 バックエンド エンジニアと緊密に連携して、フロントエンド インターフェイスが厳格な OAuth スコープを適切に維持し、エンタープライズ グレードのセキュリティ プロトコルを尊重できるようにしました。
- **Jira 内の摩擦のない UI/UX:** Jira 課題パネル内に直接埋め込まれた応答性の高い UI を設計しました。 私は、スムーズな「ワンクリック」時間ロギングとカスタム時間枠 (日次、週次、月次) の機能を設計し、エンジニアが時間を追跡する際に通常直面するコンテキスト切り替えによるペナルティを排除しました。
- **リアルタイム データおよびレポート パイプライン:** 組織の生産性に関するライブ更新を処理および表示する、包括的なデータ視覚化ダッシュボードを構築しました。 さらに、私は堅牢な輸出パイプラインを設計し、プロジェクトの関係者が正確な財務配分のためにカスタマイズ可能なオンデマンドのレポートを CSV および PDF 形式で即座に生成できるようにしました。

![Timesheets by AppForest — Time Logging](/projects/timesheets-appforest/time-logging.gif)

## ビジネスへの影響

この特注の社内ソリューションに組織を移行することで、高価なサードパーティ SaaS プロバイダーへの依存を完全に排除し、会社は即座に **年間 9,000 ドル** 以上を節約できました。 このプラグインは、当面のコスト削減にとどまらず、リーダーにチームの速度とプロジェクトのコストを前例のないリアルタイムで可視化することを可能にし、リソースの予測と全体的な関係者のコミュニケーションを劇的に改善しました。
