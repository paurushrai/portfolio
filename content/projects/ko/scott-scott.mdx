국제 로펌인 [Scott+Scott](https://scott-scott.com/)에서, 나는 그들의 메인 WordPress 사이트를 맡았다. 목표는 크고 기존에 있던 사이트를 현대화하는 것이었다 — 커스텀 컴포넌트로 UX를 개선하고, 페이지를 의미 있게 더 빠르게 만드는 것.

![Scott+Scott](/projects/scott-scott/image.png)

## 내가 한 일

- **커스텀 컴포넌트:** WordPress 안에 인터랙티브한 프론트엔드 컴포넌트를 만들어, 사이트의 법률 콘텐츠를 잠재 고객이 더 읽고 탐색하기 쉽게 했다.
- **Core Web Vitals:** 성능 문제를 짚어내고, 고쳐야 할 이유를 설득한 뒤, 그 작업을 이끌었다 — 에셋 압축, 캐싱, 더 나은 이미지 전달 — 로딩 시간을 낮추고 사이트의 Lighthouse 점수를 개선했다.
- **유지관리와 보안:** 지속적인 유지관리를 맡았다 — 보안 패치, 데이터베이스 최적화, 그리고 트래픽이 몰리는 보도 발표 동안 사이트를 안정적으로 유지하기 위한 로펌과의 조율.

## 왜 중요했나

사이트는 결국 더 빠르고 안정적이 됐다. Core Web Vitals 개선은 검색 순위에 도움이 됐고, 커스텀 컴포넌트는 잠재 고객에게 더 깔끔한 경험을 줬다.
