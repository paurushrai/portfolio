이 포트폴리오는 단순한 템플릿이 아닌, 살아있는 엔지니어링 산출물로 기능하도록 설계된 **Next.js 14 App Router** 애플리케이션입니다. 모든 아키텍처 결정은 엔터프라이즈 시스템에 적용하는 것과 동일한 프로덕션급 사고방식 — 정확성, 관찰 가능성, 측정 가능한 성능 — 을 바탕으로 이루어졌습니다. 이 사이트는 **데스크톱 99/100, 모바일 97/100의 Lighthouse 성능**을 달성하며, 접근성과 SEO 모두 완벽한 100점을 기록했습니다.

## 기술적 범위 및 기여

- **12개 언어 i18n 아키텍처:** 서드파티 라이브러리 없이 완전히 커스텀 국제화 시스템을 처음부터 설계하고 구현했습니다. 영어, 독일어, 스페인어, 프랑스어, 힌디어, 이탈리아어, 일본어, 한국어, 포르투갈어, 러시아어, 터키어, 중국어에 걸쳐 강타입 번역 맵을 갖춘 타입 안전 `LanguageContext`를 구축했습니다. 언어 전환기는 `localStorage`를 통해 사용자 설정을 유지하고 `<html lang>` 속성을 동적으로 업데이트하여, 스크린 리더와 크롤러가 항상 올바른 로케일을 인식하도록 보장합니다. 연락 양식 레이블, 오류 상태, CTA 문구를 포함한 모든 사용자 대면 문자열이 12개 로케일 전체에 걸쳐 완전히 현지화되어 있습니다.

- **Canvas 애니메이션 및 성능 엔지니어링:** 마우스 기반 자기력, 알파 페이드 물리 연산, 부드러운 경계 감싸기를 갖춘 WebGL급 파티클 시스템을 순수 Canvas 2D API로 직접 구현했습니다. 핵심 강제 리플로우 병목점을 발견하고 제거했습니다 — `getBoundingClientRect()` 호출을 핫 `mousemove` 경로에서 제거하여 리사이즈 이벤트에서만 업데이트되는 캐시된 `ref`로 이동시켜, 프레임당 DOM 스래시를 O(n)에서 O(1)로 줄였습니다. RAF 쓰로틀링된 마우스 상태 업데이트 및 `next/dynamic` 레이지 로딩과 결합하여 파티클을 크리티컬 렌더 경로에서 완전히 제외시킴으로써 데스크톱 Lighthouse 성능 점수를 **99/100**으로 끌어올렸습니다.

- **광고 차단기 사각지대 없는 애널리틱스 스택:** 이중 애널리틱스 설정(Umami + Google Tag Manager)을 구성하고, 모든 텔레메트리를 퍼스트파티 도메인을 통해 라우팅하는 Next.js 리라이트 프록시를 구축했습니다(`/um/script.js` → `cloud.umami.is`, `/um/api/send` → `api-gateway.umami.dev`). 이를 통해 uBlock Origin과 Brave가 서드파티 출처의 애널리틱스 스크립트를 차단할 때 일반적으로 발생하는 20~40%의 무음 이벤트 손실을 제거했습니다. GTM은 GA4 태그를 서버 사이드에서 관리하여 모든 태그 거버넌스를 한 곳에 통합합니다.

- **SEO 및 구조화 데이터 스위트:** JSON-LD `Person` 스키마, 12개 로케일 전체에 대한 hreflang 대체 링크, 라우트별 canonical URL, 모든 프로젝트 슬러그에 대한 동적 `generateMetadata`를 구현했습니다. `generateMetadata`를 구성하여 프로젝트별 Open Graph와 `SoftwareApplication` JSON-LD를 생성함으로써 Google의 구조화 데이터 유효성 검사기를 충족하고 현지화된 라우트 전반에 걸친 중복 콘텐츠 신호를 제거했습니다.

- **WCAG 2.1 AA 접근성:** 전체 접근성 감사를 수행하고 모든 실패 항목을 수정했습니다 — 시각적으로 숨겨진 콘텐츠 건너뛰기 링크 구현, 단일 CSS 규칙으로 전역 `:focus-visible` 키보드 링 적용, 모든 본문 텍스트의 전경/배경 대비율 수정(어두운 배경에서 zinc-500 → zinc-400으로 변경 시 AA 대비 4.5:1+ 충족), 장식용 canvas 요소에 `aria-hidden` 적용. 언어 전환기를 비의미적인 `listbox`에서 적절한 ARIA `menu` 구조로 리팩터링했습니다.

- **타입 안전 콘텐츠 파이프라인:** 빌드 시점에 MDX 프로젝트 파일을 완전히 타입화된 정적 JSON으로 처리하도록 Contentlayer를 구성했습니다. 파일 경로 구조에서 순수하게 파생된 `slug` 및 `locale` 계산 필드를 포함합니다. 새 프로젝트를 추가할 때 코드 변경이 전혀 필요 없습니다 — 올바른 로케일 폴더에 MDX 파일을 넣기만 하면 다음 배포 시 사이트에 자동으로 표시됩니다. 런타임 파싱 오버헤드를 완전히 제거했습니다.

- **서버리스 페이지뷰 추적:** SHA-256 해시된 IP 주소로 중복 제거를 처리하는 익명 페이지뷰 카운팅용 서버리스 Edge Function을 구축했습니다 — 쿠키 없음, PII 저장 없음. 카운트는 60초 ISR 윈도우에서 재검증되어, 정적 전달 모델을 희생하지 않고도 프로젝트 조회수가 실시간에 가깝게 느껴지도록 합니다.

## 비즈니스 임팩트

이 포트폴리오는 의도적인 기술 역량의 증명입니다. 파티클 시스템의 강제 리플로우 병목점 제거부터 퍼스트파티 애널리틱스 프록시 구축, 12개 로케일 콘텐츠 마이그레이션 완료에 이르기까지 — 모든 최적화는 대규모 프로덕션 시스템에 적용하는 것과 동일한 엔지니어링 엄격함에 의해 추진되었습니다. 그 결과: 접근성과 SEO에서 완벽한 점수, 거의 완벽한 성능, 수십억 명의 비영어권 사용자가 접근 가능한 완전 현지화된 콘텐츠 서피스, 그리고 다른 구현이 무음으로 버리는 데이터를 포착하는 애널리틱스 파이프라인. 코드베이스는 오픈 소스이며 — 아키텍처 결정은 주장이 아닌 감사 가능한 형태로 공개되어 있습니다.
