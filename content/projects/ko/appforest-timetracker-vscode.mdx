내부 Jira 플러그인이 Testlify에서 시간 추적을 성공적으로 중앙 집중화했지만 개발자는 여전히 시간을 수동으로 기록하기 위해 매일 컨텍스트를 전환해야 하는 어려움에 직면했습니다. 이러한 관리 부담을 완전히 없애기 위해 엔지니어가 IDE를 떠나지 않고도 로깅 프로세스를 자동화하는 기본 Visual Studio Code 확장인 **AppForest Timetracker**를 혼자서 설계, 구축 및 출시했습니다. 

## 기술 범위 및 기여 

- **VS 코드 확장 아키텍처:** 공식 VS 코드 확장 API를 활용하여 완전히 처음부터 확장을 구축했습니다. 활성 편집기 시간, 파일 전환 및 작업 공간 수정 사항을 자동으로 모니터링하여 최종 사용자에게 중단 없는 환경을 보장하는 경량 백그라운드 프로세스를 개발했습니다. 
- **Git Branch 및 Jira 동기화:** 개발자의 로컬 Git 환경과 보안 Jira REST API 간의 지능형 데이터 브리지를 엔지니어링했습니다. 확장 프로그램은 현재 활성 Git 분기를 자동으로 구문 분석하고 관련 티켓 ID를 추출하며 정확한 상황 인식 시간 로그를 Atlassian 생태계에 직접 푸시합니다. 
- **End-to-End Solo Execution:** 전체 제품 수명주기의 단독 소유자로 운영됩니다. 저는 로컬 구성 UX 개념화와 보안 OAuth 토큰 암호화 처리부터 Microsoft Visual Studio Marketplace에 최종 빌드를 패키징하고 게시하는 것까지 모든 것을 관리했습니다. 

## 비즈니스 영향 

지루한 조직의 잡일을 눈에 보이지 않는 자동화된 데이터 파이프라인으로 전환함으로써 이 확장은 엔지니어링 속도에 지대한 영향을 미쳤습니다. **수동으로 시간을 추적하는 노력이 60~70% 감소**하고 **인적 보고 오류가 무려 80%나 감소**하는 데 성공했습니다. 그 결과, 매우 정확하고 원활한 데이터가 유입되면서 리더십은 스프린트 계획의 정확성과 청구 정확성을 획기적으로 향상시키는 데 필요한 정확한 정보를 얻을 수 있었습니다.
