우리 Jira 플러그인인 [Timesheets by AppForest](/projects/timesheets-appforest)는 Testlify의 시간 추적을 한곳으로 모아줬지만, 개발자들은 여전히 작업을 멈추고 넘어가서 직접 시간을 기록해야 했다. AppForest Timetracker는 그 간극을 메운다. 에디터 안에서 코딩 활동을 추적하고 시간 기록을 빠른 동작 하나로 바꿔주는 VS Code 확장 프로그램이라, 엔지니어가 IDE를 벗어나지 않고도 Timesheets에 기록할 수 있다. 아이디어부터 Marketplace 게시까지 처음부터 끝까지 내가 맡았다.

## 내가 만든 것

- **확장 프로그램 자체:** 공식 VS Code Extension API 위에 만들었고, 백그라운드 프로세스가 활성 에디터 시간, 파일 전환, 워크스페이스 변경을 조용히 추적한다, 개발자를 방해하는 건 아무것도 없다.
- **Git을 인식하는 시간 기록:** 확장 프로그램이 현재 Git 브랜치를 읽어 거기서 티켓 ID를 뽑아낸다. 그래서 캡처한 시간이 Timesheets 플러그인에 기록될 때 이미 올바른 이슈에 연결되어 있다, 티켓을 찾을 필요도, 다시 입력할 필요도 없다.
- **전체 수명주기:** 로컬 설정 UX, 안전한 토큰 저장, 그리고 빌드를 Visual Studio Marketplace에 패키징하고 게시하는 일까지 처리했다.

## 왜 중요했나

기록에서 수동 단계를 없애자 Timesheets로 들어오는 시간 데이터가 더 완전하고 정확해졌다, 시간 기록에 드는 노력이 대략 60~70% 줄었고 보고 오류도 훨씬 적어졌다. 덕분에 리더십은 스프린트 계획과 청구에 쓸 더 깨끗한 데이터를 갖게 됐다.
