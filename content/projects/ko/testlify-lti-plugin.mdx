Canvas, Moodle 및 Blackboard와 같은 학습 관리 시스템(LMS)은 교육 기관 및 기업 교육 부문의 운영 허브입니다. 이러한 대규모 생태계에 대한 Testlify의 인재 평가 기능을 활용하려면 매우 안전하고 규정을 준수하는 브리지가 필요했습니다. 솔로 풀 스택 엔지니어로 적극적으로 활동하면서 저는 강사의 기본 LMS 환경 내에서 Testlify를 직접 연결하도록 설계된 원활한 통합인 **Testlify LTI 플러그인**을 설계하고 출시했습니다. 

![Testlify LTI 1.3 Plugin Demo](/projects/testlify-lti-plugin/plugin.gif)

## 기술 범위 및 아키텍처 

- **사용자 정의 LTI 1.3 암호화 엔진:** 앞서 언급한 무거운 블랙박스 타사 LTI 라이브러리를 사용하지 않고 Next.js 14 내에서 매우 안전한 사용자 정의 구현을 처음부터 설계했습니다. 엄격한 OIDC(OpenID Connect) 핸드셰이크를 직접 수행하고, 심층적인 JWT 서명 확인을 처리하고, 안전한 JWKS 공개 키 엔드포인트를 설정하여 LMS와 플랫폼 간의 뚫을 수 없는 신뢰를 보장했습니다. 
- **자동화된 데이터 동기화:** 지루한 관리 워크플로우를 자동화하기 위해 정교한 API 계층을 설계했습니다. NRPS(이름 및 역할 프로비저닝 서비스)를 통합하여 대규모 학생 명단을 즉시 동기화하고 AGS(과제 및 성적 서비스)를 활용하여 후보자 평가 점수를 LMS 성적 기록에 바로 원활하게 반영하는 강력한 웹훅 리스너를 구축했습니다. 
- **풀 스택 시스템 설계:** 복잡한 다중 테넌트 API 라우팅과 세련되고 액세스 가능한 React 18 대시보드 UI를 단일 모놀리식 아키텍처로 통합했습니다. 저는 안전한 LMS 플랫폼 구성을 처리하기 위해 확장 가능한 MongoDB 스키마를 설계했고, 로컬 테스트를 위해 격리된 LMS 환경을 시뮬레이션하기 위해 고급 Docker 설정을 조율했습니다. 

## 비즈니스 영향 

마찰이 없고 보편적으로 호환되는 LTI 통합을 성공적으로 엔지니어링함으로써 이 프로젝트는 Testlify의 대상 시장을 고등 교육 및 기업 교육 부문으로 공격적으로 확장했습니다. 자동화된 SSO(Single Sign-On) 및 자동 성적 동기화는 관리상의 마찰을 완전히 제거하여 강사가 쉽게 플랫폼을 채택하고 대규모 기관 참여를 유도할 수 있도록 했습니다.
