हमारे Jira प्लगइन, [Timesheets by AppForest](/projects/timesheets-appforest), ने Testlify में समय ट्रैकिंग को केंद्रीकृत कर दिया था, लेकिन डेवलपर्स को फिर भी रुककर स्विच करना पड़ता था ताकि वे अपने घंटे हाथ से लॉग कर सकें। AppForest Timetracker उसी खाई को पाटता है। यह एक VS Code एक्सटेंशन है जो एडिटर में ही कोडिंग गतिविधि को ट्रैक करता है और समय लॉग करने को एक झटपट क्रिया में बदल देता है, ताकि इंजीनियर IDE छोड़े बिना Timesheets में लॉग कर सकें। मैंने इसे शुरू से आखिर तक संभाला, विचार से लेकर Marketplace पर पब्लिश करने तक।

## मैंने क्या बनाया

- **एक्सटेंशन खुद:** आधिकारिक VS Code Extension API पर बना, जिसमें बैकग्राउंड प्रोसेस चुपचाप सक्रिय एडिटर समय, फाइल स्विच और वर्कस्पेस बदलावों को ट्रैक करते हैं, कुछ भी डेवलपर को बीच में नहीं टोकता।
- **Git-समझदार समय लॉगिंग:** एक्सटेंशन मौजूदा Git ब्रांच को पढ़ता है और उसमें से टिकट ID निकाल लेता है, ताकि जो समय यह कैप्चर करता है वह Timesheets प्लगइन में लॉग होने पर पहले से ही सही इश्यू से जुड़ा हो, न टिकट ढूंढना पड़े, न दोबारा टाइप करना।
- **पूरा जीवनचक्र:** मैंने लोकल कॉन्फिग UX, सुरक्षित टोकन स्टोरेज, और बिल्ड को Visual Studio Marketplace पर पैकेज करके पब्लिश करने का काम संभाला।

## यह क्यों मायने रखता था

लॉगिंग से हाथ का कदम हटाने का मतलब था कि Timesheets में आने वाला समय डेटा ज़्यादा पूरा और ज़्यादा सटीक हुआ, घंटे लॉग करने में लगने वाली मेहनत में लगभग 60–70% की गिरावट और कहीं कम रिपोर्टिंग गलतियां। इससे लीडरशिप को स्प्रिंट प्लान करने और बिलिंग के लिए ज़्यादा साफ डेटा मिला।
