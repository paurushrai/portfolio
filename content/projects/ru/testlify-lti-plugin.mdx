Системы управления обучением (LMS), такие как Canvas, Moodle и Blackboard, являются операционными центрами для образовательных учреждений и секторов корпоративного обучения. Чтобы раскрыть возможности Testlify по оценке талантов для этих огромных экосистем, требовался исключительно безопасный и совместимый мост. Активно работая в качестве самостоятельного инженера полного стека, я разработал и выпустил **Testlify LTI Plugin**, бесшовную интеграцию, предназначенную для подключения Testlify непосредственно к собственной среде LMS преподавателя. 

![Testlify LTI 1.3 Plugin Demo](/projects/testlify-lti-plugin/plugin.gif)

## Технический объем и архитектура 

- **Пользовательский криптографический механизм LTI 1.3:**. Вышеупомянутые тяжелые сторонние библиотеки LTI в черном ящике я разработал с нуля высокобезопасную специальную реализацию внутри Next.js 14. Я вручную выполнил строгие рукопожатия OpenID Connect (OIDC), провел глубокую проверку подписей JWT и установил безопасные конечные точки открытого ключа JWKS, чтобы гарантировать непроницаемое доверие между LMS и платформой. 
- **Автоматическая синхронизация данных.** Создан сложный уровень API для автоматизации утомительных административных рабочих процессов. Я интегрировал службы предоставления имен и ролей (NRPS) для мгновенной синхронизации огромных списков учащихся и создал надежные прослушиватели веб-перехватчиков, которые используют службы назначения и оценок (AGS) для беспрепятственного возврата оценок кандидатов обратно в журнал оценок LMS. 
- **Полнофункциональное проектирование системы.** Унифицированная сложная многопользовательская маршрутизация API и усовершенствованный, доступный пользовательский интерфейс панели управления React 18 в единой монолитной архитектуре. Я разработал масштабируемые схемы MongoDB для работы с безопасными конфигурациями платформы LMS и организовал расширенные настройки Docker для моделирования изолированных сред LMS для локального тестирования. 

## Влияние на бизнес 

Благодаря успешной разработке беспрепятственной, универсально совместимой интеграции LTI, этот проект агрессивно расширил целевой рынок Testlify за счет секторов высшего образования и корпоративного обучения. Автоматизированная система единого входа (SSO) и автоматическая синхронизация оценок полностью устранили административные трудности, предоставив преподавателям возможность легко внедрить платформу и стимулируя массовое взаимодействие с учебными заведениями.
