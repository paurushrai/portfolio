Embora nosso plug-in Jira interno tenha centralizado com sucesso o rastreamento de tempo no Testlify, os desenvolvedores ainda enfrentavam o atrito diário da mudança de contexto para registrar manualmente suas horas. Para eliminar completamente essa carga administrativa, projetei, desenvolvi e enviei sozinho o **AppForest Timetracker**, uma extensão nativa do Visual Studio Code que automatiza o processo de registro em log sem exigir que os engenheiros saiam do IDE.

## Escopo Técnico e Contribuições

- **Arquitetura de extensão do VS Code:** Construiu a extensão inteiramente do zero, utilizando a API oficial da extensão do VS Code. Desenvolvi processos leves em segundo plano para monitorar silenciosamente o tempo ativo do editor, transições de arquivos e modificações no espaço de trabalho, garantindo uma experiência sem interrupção para o usuário final.
- **Sincronização Git Branch e Jira:** Projetamos uma ponte de dados inteligente entre o ambiente Git local do desenvolvedor e APIs REST seguras do Jira. A extensão analisa automaticamente o branch ativo atual do Git, extrai o ID do ticket relevante e envia registros de tempo precisos e sensíveis ao contexto diretamente para nosso ecossistema Atlassian.
- **Execução Solo de ponta a ponta:** Operado como o único proprietário de todo o ciclo de vida do produto. Gerenciei tudo, desde a conceituação da UX da configuração local e o manuseio da criptografia segura do token OAuth, até o empacotamento e publicação da versão final no Microsoft Visual Studio Marketplace.

## Impacto nos negócios

Ao transformar uma tarefa organizacional tediosa em um pipeline de dados automatizado e invisível, essa extensão teve um efeito profundo na velocidade da engenharia. Ele **reduziu com sucesso os esforços manuais de controle de tempo em 60–70%** e **cortou erros de relatórios humanos em impressionantes 80%**. O fluxo resultante de dados extremamente precisos e sem atrito forneceu à liderança exatamente o que eles precisavam para melhorar drasticamente a precisão do planejamento do sprint e a precisão do faturamento.
